# Campus Garden Image Audit

This repository contains a sample webpage for an in-class Chapter 6 image audit.

## Your task

The page contains **exactly three image-related problems**. Other images demonstrate appropriate choices, so do not assume every image is incorrect.

For each problem you find, record:

1. The image or page location
2. The evidence that shows it is a problem
3. A specific recommended correction
4. Who benefits from the correction

Do not edit the files until your instructor tells you to begin the repair phase.

## Run the page

Open `index.html` in a browser. You may also use your editor's local preview server. Use the browser developer tools and inspect both the HTML and the files in `assets/images`.

## Suggested workflow

1. Create a branch named `image-audit-fixes`.
2. Diagnose all three problems before editing.
3. Make and test your corrections.
4. Commit your work with a descriptive message.
5. Open a pull request explaining what you changed and why.

## Boundaries

- There are exactly three intentional image problems.
- Do not redesign the page or change its written content.
- Your fixes should preserve the overall appearance and meaning of the page.
